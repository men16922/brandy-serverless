## 🎥 Production Notes

### Visual Elements to Include:

1. **Screen Recordings**:
   - Streamlit UI walkthrough
   - Real-time API responses
   - Bedrock-generated content appearing

2. **Diagrams**:
   - AWS Architecture diagram
   - Workflow sequence diagram
   - Bedrock integration diagram

3. **Text Overlays**:
   - Key metrics ($0.20 cost, 5 minutes, 99% savings)
   - Technology stack (Bedrock Claude, Titan, SAM)
   - GitHub URL

4. **Transitions**:
   - Smooth transitions between sections
   - Highlight important UI elements with zoom/arrows
   - Use fade effects for diagram explanations

### Recording Tips:

1. **Preparation**:
   - Test the workflow multiple times
   - Prepare a fresh session for recording
   - Ensure all services are running smoothly

2. **Pacing**:
   - Speak clearly and at moderate pace
   - Pause briefly between sections
   - Keep energy level high but professional

3. **Technical Setup**:
   - 1920x1080 resolution
   - Clear audio (use good microphone)
   - Screen recording at 30fps minimum

4. **Editing**:
   - Speed up waiting times (image generation)
   - Add background music (subtle, professional)
   - Include captions for key points
